## 沿用的 App 快照

`dist/index.html`、App JavaScript、樣式、牌庫資料與 78 張牌圖，來自工作區既有「魔法師的學徒」App。本次僅複製到獨立作業目錄，沒有變更原始檔案。

原專案 README 記錄：圖片來自 Wikimedia Commons／TaionWC 的 Rider–Waite–Smith Pam-A 系列，原畫作者 Pamela Colman Smith；分類及速查結構參考 <https://nes-tarot.com/tarot-cartomantic-meanings/>，解說由原專案另行撰寫。

小牌 56 張的逐張來源網址、下載位置、尺寸與雜湊已保存在 `minor-card-sources.json`。原工作區未附同格式的大牌逐張來源清單，因此此處不捏造其個別來源網址或授權結論。後續新增／替換素材前，需記錄可核對的來源與授權。

本作業沒有將第三方圖片重新授權為自己的作品，也沒有新增通用 LICENSE 來涵蓋未核實的第三方資產。
