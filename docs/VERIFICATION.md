# 驗證紀錄

日期：2026-11-10

## 已驗證

- `npm run build`：兩篇 JSON 學習單元通過欄位、slug、章節、練習步驟與牌卡 ID 驗證，產生四個網頁。
- `npm run check`：78 個唯一牌卡 ID、牌義欄位、78 張 JPEG 圖片、分類數量、JavaScript 語法與 PWA manifest 通過。
- 產生結果一致性：四個輸出頁面與內容來源及模板一致。
- 相對路徑檢查：四個頁面中 31 個本機連結／素材都存在；每頁使用 zh-Hant 並只有一個 h1。
- 本機 HTTP：作業入口、規則網頁、兩篇文章可讀取。
- 模擬 DOM：App 載入 78 張牌、三種卡池可抽牌，沒有 DOM 執行錯誤。
- 原 App 保護：作業建立前後比對原 `app/dist` 檔案 SHA-256，內容一致。
- 隔離：獨立 port 4174、獨立 localStorage key、獨立 Service Worker 快取前綴及獨立 Vercel 專案。
